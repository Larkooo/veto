# Data provenance

`bootstrap.jsonl` contains original authored examples generated by `training/seed.py`. It is covered by the repository's MIT license.

`reviewed-development.jsonl` and `frozen-site-audit.jsonl` contain limited DOM-state examples from public pages visited on September 17, 2026. Every record identifies its source URL and publisher group. Labels and review annotations are original project material; underlying publisher text, identifiers, and URLs retain their original ownership and are not relicensed by this project. No publisher affiliation or endorsement is implied.

The development examples came from The Guardian, Ars Technica, The Verge, and Wikipedia. The selected frozen audit came from PC Gamer, Wired, CNN, and MDN. Collection used fresh unauthenticated browser profiles. The extension itself does not collect, upload, or persist page content.

The captures are small and selected. They are not a comprehensive dataset, an independent annotation study, or evidence of representative website accuracy. See the main README and reports for how they were used and the limits of the evaluation.
